Solicitação de Exclusão de Dados

Esta página fornece informações para usuários do aplicativo Relatórios Técnicos PRO, desenvolvido por WOSVIP, que desejam solicitar a exclusão de dados relacionados ao uso do aplicativo.

Como solicitar a exclusão

Para solicitar a exclusão de dados, envie um e-mail para:

wellington_wos@ymail.com

No assunto do e-mail, informe: Solicitação de exclusão de dados - Relatórios Técnicos PRO .

Na mensagem, informe que deseja solicitar a exclusão dos dados relacionados ao uso do aplicativo Relatórios Técnicos PRO. Forneça somente as informações necessárias para que a solicitação possa ser identificada e processada.

Etapas da solicitação

  1. Envie a solicitação para o endereço de e-mail informado nesta página.
  2. A solicitação será analisada para identificar os dados aplicáveis que estejam sob controle do desenvolvedor.
  3. Quando aplicável, os dados identificados serão excluídos.
  4. O usuário poderá receber uma resposta sobre o processamento da solicitação pelo endereço de e-mail utilizado no pedido.

Dados que podem ser excluídos

O Relatórios Técnicos PRO não oferece criação de conta de usuário dentro do aplicativo.

Mediante solicitação do usuário, poderão ser excluídos os dados relacionados ao uso do aplicativo que estejam armazenados e sob controle do desenvolvedor, quando aplicável.

Dados mantidos e período de retenção

Determinados dados poderão ser mantidos somente quando necessário para cumprimento de obrigações legais, regulatórias, de segurança ou para o exercício regular de direitos.

Nesses casos, os dados serão mantidos somente pelo período necessário ou pelo período exigido pela legislação aplicável e, posteriormente, serão excluídos ou tratados de acordo com as obrigações legais aplicáveis.
